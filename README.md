# Лабораторная работа №4

«Путеводитель по Хоринису» — доработка фанатского сайта по игре «Готика» из ЛР №2 🗡️

- `index.html` — главная страница с приветствием и анимацией меча
- `bestiary.html` — таблица существ и ссылка на Gothic Wiki
- `advice.html` — советы по выживанию и сундук, который открывается по клику
- `hero.html` — анкета героя с именем или прозвищем, уровнем и галочкой согласия
- `style.css` — общий файл стилей
- `chest.js` — открытие и закрытие сундука
- `hero.js` — обработка анкеты и вывод данных в консоль браузера
- `server.mjs` — локальный сервер на Node.js

**Что использовала:**

- **Flexbox** — для вёрстки главной страницы
- **Grid** — для вёрстки бестиария
- **CSS-переменные** — для всех цветов в стилях
- **CSS-анимацию** — меч плавно поднимается и опускается с помощью `@keyframes`
- **HTML-форму** — текстовое поле, числовое поле и флажок. Анкета отправляется на сервер POST-запросом, а ответ появляется под кнопкой
- **Класс `HeroRecord`** — конструктор сохраняет данные анкеты, а метод `printToConsole()` выводит их таблицей в консоль браузера
- **БЭМ** — для названий классов, например `chest`, `chest__lid` и `chest--open`

**Запуск локального сервера** (из корня проекта)\
`node lab4/server.mjs`

После запуска сайт доступен по адресу [http://127.0.0.1:3000/](http://127.0.0.1:3000/).
