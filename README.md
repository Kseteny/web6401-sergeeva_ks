# Лабораторная работа №2

«Путеводитель по Хоринису» — фанатский сайт по игре «Готика» 🗡️

- `index.html` — главная страница: приветствие герою, список того, что его ждёт, картинка с мечом
- `bestiary.html` — таблица существ с выравниванием по левому краю, по центру и по правому краю, ссылка на [Gothic Wiki](https://gothic.fandom.com/ru/wiki/Gothic)
- `advice.html` — советы выживания и картинка с сундуком
- `style.css` — общий файл стилей
- `images/` — картинки `sword.svg` и `chest.svg`

Что использовала:

- **Блочные элементы:** `div`, `p`, `h1`, `h2`, `ul`, `ol`, `table`
- **Строчные элементы:** `a`, `b`, `i`, `span`, `img`
- **Селекторы CSS:** по тегу (`body`), по классу (`.block`), по id (`#site-title`), селектор потомка (`.menu a`), псевдокласс (`:hover`)
- **Выравнивание в таблице:** классы `.left`, `.center`, `.right`

# Лабораторная работа №3

**Задание:** написать набор функций на JavaScript по каркасу проекта
[js-tasks](https://github.com/teach-kirshdv/js-tasks).

**Реализованные функции** (файл `lab3/src/core.js`):
- `isInteger` — проверка на целое число с помощью побитовых операторов
- `even` — массив чётных чисел от 2 до 20
- `sumTo` — сумма чисел до n через цикл
- `recSumTo` — сумма чисел до n через рекурсию
- `factorial` — факториал числа
- `isBinary` — проверка, является ли число степенью двойки
- `fibonacci` — n-е число Фибоначчи
- `getOperationFn` — функция с сохранением значения (замыкание)
- `sequence` — генератор арифметической последовательности
- `deepEqual` — глубокое сравнение объектов

**Запуск тестов** (из папки `lab3`):<br>
npm install<br>
npm test
